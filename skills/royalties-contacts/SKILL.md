# Look up royalties or contacts

Access follows the signed-in user's permissions.

## Royalties

1. If the user belongs to more than one workspace, ask which one.
2. List the royalty imports.
3. If asked, open one import and summarize the rows that matched a release.
4. Do not return or reproduce the raw royalty file.

## Contacts

1. List the contacts in the workspace the user names.
2. Show only what the tools return.

## If access is denied

- If royalties or contacts are not visible to the user, stop and say that section is hidden.
- Do not invent contacts, amounts, or rows.
- If a visible list is empty, say there is nothing there yet.
