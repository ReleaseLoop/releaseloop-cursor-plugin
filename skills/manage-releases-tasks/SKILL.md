# Create or update releases and tasks

## Releases

- Create a draft release with a title, an artist, and a release date. Find the artist first if needed.
- Statuses are Draft, Scheduled, Released, and Archived.
- If asked to create the same release again, keep the first one and say no copy was made.
- When changing a status, leave deal terms, owner share, and files alone. If something cannot be changed, stop and report what it was.

## Tasks

- Task statuses are To do, In progress, Done, and Approved.
- A task can sit on a release, on an artist, or stand alone.
- A task on a release can have a phase, for example Marketing. Keep it on the release, not the artist.
- A standalone to-do must not be given a phase.
- If asked to create the same task again, keep the first one.

## Limits

- If the user belongs to more than one workspace, ask which one.
- Never delete records. Deleting and processing payments are not supported.
- Do not change deal terms or file links.
